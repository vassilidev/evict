Evict is a free, open source disk space analyzer for macOS, Windows and Linux (see how it maps your disk). Every file comes from the GitHub releases, built and tested by CI.

Evict for macOS

One universal app for Apple Silicon and Intel, on macOS 11 Big Sur or later.

  • Signed and notarized by Apple: it opens like any other app, no Gatekeeper warning.
  • Drag Evict into Applications from the disk image, then allow Full Disk Access in the settings it opens.
  • Updates are built in: Evict checks GitHub at launch and every 6 hours, and installs a new version in one click, only if it's signed by Evict's developer.

Evict for Windows

One installer for every PC on Windows 10 or 11: Intel and AMD (x64), ARM64 (Snapdragon) and 32-bit. It installs for your account, no administrator rights needed.

Or install it from PowerShell, which also updates it:

irm https://vassilidev.github.io/evict/install.ps1 | iex

The script downloads the installer from the latest release and checks its SHA-256 first. Read it before running it if you like.

  • SmartScreen may warn you the first time: the installer isn't code-signed yet. Click More info, then Run anyway. The PowerShell line doesn't trigger it.
  • Evict shows up in the Start menu, and uninstalls from Settings → Apps like any app.
  • Updates are built in: Evict checks GitHub at launch and every 6 hours, and installs a new version in one click, only if it matches the checksum GitHub published.
  • Microsoft Edge WebView2 draws the window. Windows 11 and up-to-date Windows 10 have it; otherwise Evict offers to install it from Microsoft.

Evict for Linux

One line installs Evict with the native package for your distribution: the package manager brings the dependencies (it asks for your password) and Evict shows up in your app menu. Run it again to update.

curl -fsSL https://vassilidev.github.io/evict/install.sh | sh

apt gets the .deb, dnf and zypper the .rpm, pacman the Arch package; other glibc distributions get the tarball in ~/.local. Read the script before running it if you like. To uninstall: curl -fsSL https://vassilidev.github.io/evict/install.sh | sh -s -- --uninstall.

Requirements

  • 64-bit: x86_64 (Intel, AMD) or ARM64
  • glibc 2.31 or later, so not Alpine or other musl distributions
  • WebKitGTK 4.1 or 4.0 (GTK 3), installed by the package manager

Works on

Installed, started and uninstalled on every change: Ubuntu 20.04, 22.04, 24.04 and 26.04, Debian 11, 12 and 13, Linux Mint 20, 21 and 22, Pop!_OS, Kali, Fedora 41 to 43, openSUSE Leap 15.6, Leap 16 and Tumbleweed, Arch, Manjaro, EndeavourOS, Rocky Linux and AlmaLinux 9 and 10. On Rocky and Alma 10, the installer enables EPEL for WebKitGTK. musl distributions like Alpine aren't supported.

Build from source

The scanner is one C file with no dependencies; the app is a thin native shell around the same page on every system.

macOS

Needs Apple's command line tools.

xcode-select --install
git clone https://github.com/vassilidev/evict.git && cd evict && ./install.sh

Builds Evict.app and installs it in /Applications.

Linux

Needs a C compiler and the WebKitGTK 4.1 (or 4.0) headers, for example:

sudo apt install gcc libwebkit2gtk-4.1-dev

or sudo dnf install gcc webkit2gtk4.1-devel, or sudo pacman -S gcc webkit2gtk-4.1, then:

git clone https://github.com/vassilidev/evict.git && cd evict && ./install.sh

Builds with linux/build.sh and installs into ~/.local.

Windows

Cross-compiled with llvm-mingw in a container, from macOS or Linux (or WSL) with Docker:

git clone https://github.com/vassilidev/evict.git && cd evict && windows/build.sh package

Makes .build/Evict-Setup.exe for x64, ARM64 and 32-bit PCs.

Without the app, ./evict ~/Projects scans a folder and opens the report in your browser, on macOS and Linux.

Verify your download

The SHA-256 of every file is listed above, as published on its GitHub release. Compute yours and compare.

macOS

shasum -a 256 Evict.dmg

Once installed, check Apple's notarization:

spctl --assess --verbose /Applications/Evict.app

It should say accepted and source=Notarized Developer ID.

Windows

Get-FileHash Evict-Setup.exe

In PowerShell. Windows shows the hash in uppercase: compare it without minding the case.

Linux

sha256sum evict-linux-x86_64.deb

Same for any other file: the .rpm, the Arch package or the tarball.
